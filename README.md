# FeatureMAP Tutorial

This repository contains the Quarto source for the **FeatureMAP** tutorial, including both:

- the **R package** workflow
- the **FeatureMAP Shiny** workflow

The rendered site is built from the `.qmd` files in this repository and published from the `docs/` directory.

Main entry points:

- tutorial homepage: `index.qmd`
- book configuration: `_quarto.yml`
- rendered site output: `docs/`
